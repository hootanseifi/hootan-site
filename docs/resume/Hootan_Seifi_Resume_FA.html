خلاصه حرفه‌ای

مهندس هوش مصنوعی با تمرکز بر طراحی، توسعه، ارزیابی و استقرار اپلیکیشن‌های مبتنی بر مدل‌های زبانی بزرگ (LLM)، سیستم‌های بازیابی اطلاعات (RAG) و عامل‌های هوشمند (AI Agents). دارای تجربه عملی در توسعه گردش‌کارهای عامل‌محور با LangGraph، پیاده‌سازی بازیابی ترکیبی اطلاعات، ارزیابی کیفیت پاسخ مدل‌ها و طراحی سازوکارهای امنیتی و کنترلی برای اپلیکیشن‌های هوش مصنوعی.

دارای نمونه‌کارهای عملی شامل پلتفرم سازمانی AI Agent، سامانه RAG دوزبانه و سیستم شبیه‌سازی معاملات مبتنی بر چند عامل هوشمند. فارغ‌التحصیل کارشناسی ارشد هوش مصنوعی با پیشینه فعالیت در حوزه‌های تحقیق و توسعه، تحلیل فنی نرم‌افزار و تحلیل بازارهای مالی.

مهارت‌های فنی

LLM و توسعه عامل‌های هوشمند: Python، LangGraph، LangChain، OpenAI Agents SDK، CrewAI، MCP، Tool Calling، Prompt Engineering، Structured Outputs، LLM Evaluation، Guardrails
RAG و بازیابی اطلاعات: Embeddings، Chunking، pgvector، PostgreSQL، Chroma، Hybrid Search، BM25، Reranking، RRF، Recall@k، MRR
Backend و تست: FastAPI، SQLAlchemy، Alembic، REST API، SSE، pytest، Playwright
یادگیری ماشین و داده: PyTorch، scikit-learn، XGBoost، Pandas، SQL، QLoRA، PEFT
زیرساخت و استقرار: Docker، Docker Compose، Linux، Caddy، Git، GitHub Actions، CI/CD
Frontend: Next.js، TypeScript
آشنایی: AWS Bedrock، SageMaker، Lambda، Terraform، Modal، Vercel، Spark، Kafka، Airflow
